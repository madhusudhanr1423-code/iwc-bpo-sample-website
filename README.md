# Vibrant Redesign

Update the color scheme and visual styling of this IWC BPO website to match the following palette and section-by-section pattern (keep all existing content, structure, and page layout — only update colors/styling):

Color palette:

Primary Orange: #F26522 (bold orange-red)

Accent Blue: #1E5EFF (vivid blue)

Dark/Black: #0D0D0D (near-black)

Light Mint: #E8F5F0 (pale mint/aqua)

Peach: #FDE8DC (soft peach)

White: #FFFFFF

Apply per section:

Header/Nav — light mint background (#E8F5F0), black "Get Started" button (#0D0D0D with white text)

Hero section — bold orange background (#F26522), large white heading text, white body text, blue CTA button (#1E5EFF with white text), stats numbers in white/bold

About/content sections — white background (#FFFFFF), black body text, black CTA buttons ("Learn More" style), checkmarks in blue circles

Services section — black background (#0D0D0D), white heading and text, blue icon outlines/icons

Case studies / results section — black background (#0D0D0D), white heading text, orange highlight labels for "Challenge:", "Solution:", "Results:" (bold orange text)

Pricing section — peach card backgrounds (#FDE8DC), orange accent logo/icon per card, black heading text, blue "Get Started Now" buttons (#1E5EFF with white text)

Contact/footer section — black background (#0D0D0D), white headings, grey/white body text, one circular blue CTA button (#1E5EFF), white footer link columns

Keep spacing, section order, and existing content exactly as is — this is purely a color and button-style update to match a bold orange + blue + black theme instead of the current navy-blue palette.
